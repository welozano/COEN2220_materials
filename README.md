# COEN 2220 — Programming 2
## Materiales del curso

Repositorio con los materiales del curso (lectures y laboratorios), en C++. Continuación directa de COEN 2210 (Introduction to Programming). Cada guía de lab está pensada para una sesión de 2 horas; cada lecture, para una sesión de 3 horas.

**Textbook:** Gaddis, *Starting Out with C++: From Control Structures through Objects*, 8th Edition. 

---

> 💻 **¿Necesitas repasar Git/GitHub o el uso de la terminal?** Ya se cubrió en COEN 2210 — si necesitas refrescar, consulta los materiales de ese curso.

### Cómo usar este repositorio

- Cada guía está en formato Markdown dentro de `labs/` o `lectures/`, y se puede leer directamente en GitHub (se renderiza con formato automáticamente).
- Este repo se actualiza según se van creando/revisando los materiales — el historial de commits sirve como registro de versiones de cada guía.
- El Lab 1 se reutiliza tal cual de COEN 2210 (los estudiantes ya llegan con esa base de Intro).
